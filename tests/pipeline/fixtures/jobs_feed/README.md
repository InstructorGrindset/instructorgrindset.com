Synthetic recorded responses for tests/pipeline/test_jobs_feed.py. Each file follows the response shape of the vendor's
public postings API (Greenhouse Job Board API, Lever Postings API, SmartRecruiters Posting API, Workable widget API,
Ashby Job Posting API). Employers, titles and URLs are invented. responses.json maps each request URL to its file;
"error: ..." simulates a failed request.
