# Tier A draft list

Review document for the ROADMAP Section 3 gate. Generated by `python pipeline/build.py` from `data/raw/tier_a/` and `data/raw/ownership/`. Edit the research YAML, then rebuild. Hand edits to this file are overwritten.

A resort qualifies when it meets at least one criterion: diehard following, luxury, athlete development, or heritage. Each criterion below carries its source.

**How to approve:** set `status: approved` at the top of a research batch file in `data/raw/tier_a/`. Every resort in that batch then builds with `tier_a_status: approved`.
